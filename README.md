# 옛따 시간표 (yet_tta_si_gan_phyo)

2024년 2학년 1학기 프로그래밍 설계(오후반) 5조 프로젝트. Windows 콘솔에서 과목을 검색·선택하면 시간이 겹치지 않는 시간표 조합을 만들어 보여주는 C++ 프로그램이다.

## 기능

- 시간표 생성: 과목 검색 후 선택, 가능한 조합을 이전/다음 버튼으로 넘겨 보며 하나를 고른다
- 시간표 수정
- 내 시간표 확인
- 마우스·키보드 입력 모두 지원 (Win32 Console API)

## 디렉터리

| 경로 | 내용 |
|---|---|
| `src/` | 소스 코드, Visual Studio 솔루션(`Project4.sln`) |
| `presentation/` | 주차별 발표자료 (pptx, hwp, pdf) |
| `docs/` | 설계제안서, 수행내용보고서, 최종결과보고서 |

## 빌드·실행

- Visual Studio 2022 (toolset v143), Windows 전용
- `src/Project4.sln`을 열어 빌드한다
- SDL 검사를 비활성화해야 빌드된다 (`main.cpp` 주석 참고)
- 데이터 파일 `subject.txt`(과목 목록), `schedule.txt`(저장된 시간표)를 실행 파일 작업 디렉터리에서 읽는다

### 데이터 형식

`subject.txt` — 한 줄에 과목 하나. `{요일,시작교시,종료교시}` 블록이 분반 수만큼 붙는다.

```
과목명/분반수/{요일,시작,끝}{요일,시작,끝}...
```

`schedule.txt` — 선택한 시간표. `과목명,요일,시작교시,종료교시`

## 인코딩

소스와 데이터 파일은 원래 CP949로 작성됐다. 저장소에는 UTF-8로 저장하고, 체크아웃할 때 `.gitattributes` 설정으로 CP949 + CRLF로 되돌린다.
